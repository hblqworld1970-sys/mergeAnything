# 立项方向说明（内部，不随计划书提交）

撰写日期：2026-08-20。文献均经 PubMed E-utilities 核验 PMID/DOI。

## 为何不采用原对白中的“二选一”假说

原表述把 PPARG→B6 代谢基因 与 B6 代谢→PPARG 写成互相排斥的两条路。评审会认为这是循环论证，且两者都可以是同一正反馈环路的两端，不必对立。更关键的是：2025–2026 年高分文献已表明**补充维生素 B6 有利于 CD8⁺ T 细胞干性并增强抗 PD-1 疗效**（Wu 等，*Developmental Cell*），若把“B6 代谢旺盛 = 免疫抑制”直接写成结论，会与主流方向撞车。

## 选定方向：区室化 B6 争夺 / 代谢陷阱

SPP1⁺ 巨噬细胞把微环境中的 B6 迅速磷酸化为不易外流的 PLP，形成胞内蓄积、胞外剥夺。胞内 PLP 增强 PPARG 转录输出并经 PPARG 直接驱动 *SPP1*（正反馈锁定表型）；局部 B6 剥夺使 CD8⁺ T 细胞失去干性、走向耗竭；SPP1–CD44 / SPP1–ITGA4 再叠加配体–受体打击。干预目标因此不是全身补 B6，而是**髓系限定阻断 PDXK（或 B6 摄取）**，把 B6 还给 T 细胞。

该框架同时消化三处文献压力：

1. Wu 等（*Dev Cell*）与 He 等（*Cancer Discovery*，PDAC 中肿瘤细胞与 NK 争夺 B6）支持“同一微量营养素、不同细胞、相反后果”。
2. Xue 等（*Cancers* 2026）已在结直肠癌转录组水平报告 SPP1⁺ TAM 维生素 B6 代谢升高。观察本身不再新，创新必须落在 **NSCLC 免疫治疗队列、代谢物直接测量、因果干预**。
3. Zhang 等（*J Transl Med* 2026）已报道 M2 巨噬细胞经 SPP1–CD44 促进 CD8 耗竭。配体轴不宜再当唯一创新点，应作为下游已部分成立的功能读出。

## 提交前必须补上的内容

计划书中所有 `[待填]` 均不能进网评系统，尤其是：

- 申请人单位、平台、代表作、在研基金
- 免疫治疗队列来源、例数、伦理批件
- 是否已完成 P0 预实验（SPP1⁺ vs SPP1⁻ 巨噬细胞胞内 PLP；PDXK 敲低后免疫抑制表型）
