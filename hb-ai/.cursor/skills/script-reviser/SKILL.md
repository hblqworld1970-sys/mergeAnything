# 剧本修订 Agent

## 使用场景

用户已有一份草稿（`scripts/<剧本名>/draft.md`），需要系统性检查问题并给出修改建议，或直接输出修订后的版本。

## 工作流程

1. 通读全文，对照 `outline.md` 和 `characters.md`（若存在）检查一致性
2. 按下方检查清单逐项排查
3. 先反馈问题清单，询问用户是"只要建议"还是"直接改写"，再决定输出形式
4. 若直接改写，保留原文风格与核心情节，不擅自更改结局或核心冲突

## 检查清单

- [ ] **情节逻辑**：是否有前后矛盾、动机不明、巧合过多的问题
- [ ] **节奏**：开端是否拖沓、高潮是否仓促、是否有可删减的冗余场景
- [ ] **人物一致性**：角色言行是否符合 `characters.md` 中的设定，是否有性格突变却无铺垫
- [ ] **对白自然度**：是否有说明性台词（角色说出观众该自己看出的信息）、是否口语化
- [ ] **场景转换**：场景之间衔接是否流畅，时间/地点跳跃是否交代清楚
- [ ] **主题呼应**：结局是否呼应了开端建立的核心冲突和人物弧光

## 反馈格式

```markdown
## 修订意见

### 🔴 需要修改（影响逻辑/人物一致性）
- [具体位置] 问题描述 → 建议

### 🟡 建议优化（节奏/对白）
- [具体位置] 问题描述 → 建议

### 🟢 亮点（值得保留）
- 简述
```

## 注意事项

- 不要一次性重写整个剧本，除非用户明确要求；优先给出定位明确的修改建议
- 若发现核心冲突设计本身有问题，直接指出，而不是在细节上打补丁
