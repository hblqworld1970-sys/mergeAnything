# Drama Skills（hb-ai 入口）

本 skill 是 [worldwonderer/drama-skills](https://github.com/worldwonderer/drama-skills) 在 hb-ai 中的**自动路由**，不代写所有阶段。上游十个技能把点子或长篇做成可拍文本；核心产出是剧本、设定、提示词、审查记录。图片/视频/TTS 必须先预览、经用户明确确认后再执行。

## 每次请求的起点

1. 工作目录限定在 `hb-ai/`。剧本落在 `hb-ai/scripts/<剧名>/`。
2. 用用户给出的路径；否则在 `hb-ai/scripts/` 下找最近的剧目文件夹。没有剧目且用户要开新项目时，先初始化再创作。
3. 只读完成本步所需的直接输入，不把整部剧一次性塞进上下文。
4. 每轮只做**一个阶段的一个有界批次**；完成后报告已覆盖范围、剩余范围与下一步，把控制权交还用户。不要静默连跑到投产。

## 意图路由

| 用户要做的事 | 交给 |
|---|---|
| 点子、系列承诺、改编契约、分集地图；导入多集整稿并按实际结构切片 | 故事开发（见 [pipeline.md](pipeline.md)） |
| 长篇原著值不值得改、抽样快评、章节索引 | 原著分析 |
| 写/改单集目标、节拍、可拍剧本 | 分集剧本 → `draft.md` |
| 人物、造型、地点、道具与状态 | 资产 → `assets.md`，人物摘要同步 `characters.md` |
| 大纲/情节点、分集地图 | 故事开发 → `outline.md` |
| 人物/场景/道具参考图与 Lookdev 风格帧提示词 | 图片提示词 → `image-prompts.md` |
| 场次视觉计划、镜头、冻结关键帧 | 分镜 → `storyboard.md` |
| 单镜动作、表演、运镜、声音、时间线音乐规格 | 视频提示词 → `video-prompts.md` |
| 实际生成图片、视频、TTS、音乐 | 投产：先展示本次 job，**得到明确确认后**才执行 |
| 结构/内容审查、修订结论 | 审查 → `review.md` |
| 初始化、进度/下一步、制作形态、视觉方向、Look Development、交付 | 本 skill（入口职责） |

用户的明确意图优先。Look Development 是可选分支。资产确认后，图片提示词与分镜可以并行。

## 与 hb-ai 文件的对应

从 `hb-ai/scripts/_template/` 复制出剧目目录。Drama Skills 产线在三个文学稿之外追加制作文件，缺了再按阶段创建，不要为了“跑通流水线”虚构上游文件。

| 文件 | 用途 |
|---|---|
| `characters.md` | 人物设定（可与资产中的人物条目互相同步，冲突时停下来问用户） |
| `outline.md` | 故事大纲 / 分集地图摘要 |
| `draft.md` | 单集或整剧可拍剧本 |
| `project.md` | 标题、画幅、语言、制作形态、视觉方向、当前阶段与状态 |
| `assets.md` | 人物造型、地点视图、道具状态 |
| `image-prompts.md` | 参考图与 Lookdev 提示词（只写规格，不直接出图） |
| `storyboard.md` | 分镜与关键帧 |
| `video-prompts.md` | 视频提示词与音乐规格 |
| `review.md` | 审查记录 |

对用户只使用这些状态：`draft`（未发布）、`needs_confirmation`（等用户决定）、`accepted`（已接受）、`revise`（要改）、`approved`（已确认且复核通过）、`update_needed`（直接输入已变）。不要把沉默当成接受。

## 初始化

没有剧目且用户要新建时：

1. 确认标题、项目语言、提示词语言、画幅（默认竖屏 9:16）、路径；集数或时长未知就留空。
2. 复制 `_template/` 为 `hb-ai/scripts/<剧名>/`，写入 `project.md`。不覆盖已有文件。
3. 制作形态与视觉方向保持未定，告诉用户下一步最有用的选择。
4. 初始化不自动生成故事、剧本或资产。

## 有界续跑与确认

- 「继续」或全链预览：本轮只做一个 owner 的一个连续批次，写候选，不替用户接受。
- 下一阶段、审查、投产各自需要明确请求。
- 投产必须先列出：数量、内容、参考、参数、输出位置；任何内容变化都会让上次确认失效。失败任务不能无确认重试。
- 本仓库**不内置**上游的 Python 工具、Dashboard 与生产 adapter（Seedance / GPT Image 2 / MiniMax Music）。需要真实出图出片或 `/short-drama dashboard` 时，说明需另行安装 [drama-skills](https://github.com/worldwonderer/drama-skills)，并强调凭据不写入本项目。
- 审查尽量当作独立步骤；无法隔离上下文时，标注为自检。审查只给证据和修改请求，改稿仍由原阶段负责。

## 边界

- 不把别处案例提升为本剧定律。
- 语义冲突不静默修复。
- 不批量加载整部原著或多集整稿；按文件实际结构索引，每次只读当前集。
- 歌词必须由用户提供并接受，不代写未授权歌词。
- 详细阶段清单、推荐顺序与上游技能名见 [pipeline.md](pipeline.md)。
