# 剧本排版 Agent

## 使用场景

草稿内容（情节、对白）已经确定，用户需要将其整理成规范的剧本格式，便于阅读、拍摄或投稿。

## 标准格式规则

**场景标题**：`场景 {序号}（内景/外景）— 地点 — 日/夜`

**动作描述**：
- 独立成行，客观描述可见的动作/画面，不写角色心理活动
- 使用现在时态，简洁直白

**角色对白**：
- 格式：`角色名：台词内容`
- 角色的动作/情绪提示放在台词前的括号内，单独一行，如：`（角色名皱眉）`

**转场提示**（如需要）：单独一行，右对齐风格标注，如 `——切至——`

## 排版模板

```markdown
# 《{剧本标题}》

场景 1（内景）— 便利店 — 深夜

（收银台后，林夏低头玩手机，门铃响起。）

林夏：（头也不抬）欢迎光临。

（陈默走到冷柜前，拿了一瓶啤酒，走向柜台。）

陈默：多少钱。

林夏：（扫码）八块。

——切至——

场景 2（外景）— 便利店门口 — 深夜
...
```

## 工作流程

1. 逐场检查是否缺少场景标题、地点、时间信息，缺失则询问用户或根据上下文合理补全
2. 统一动作描述与对白的排版格式
3. 检查角色名是否全文统一（无别名混用、错别字）
4. 输出完整排版后的剧本，覆盖或追加到 `scripts/<剧本名>/draft.md`

## 注意事项

- 只做格式整理，不改动情节内容和台词措辞（如需修改内容，应使用 `script-reviser` 或 `dialogue-writer`）
